# Итерация 41 — административный интерфейс

В административной панели уточнены визуальные и семантические состояния:

- заголовок закрытого контура и подписи полей приведены к русскому языку;
- поля формы темы получили явные пары `label`/`id`;
- корневой контейнер сообщает о загрузке через `aria-busy`;
- сообщения загрузки и успешного действия объявляются как живые области;
- пустые списки тем и цепочек получили понятные сообщения, как уже было для
  списка жалоб.
- длинные слова в крупных заголовках переносятся внутри карточки, поэтому
  экран входа не обрезает слово «администратора» на обычной ширине.

Добавлен `tests/unit/admin-visual-source.test.ts`. Он проверяет локальный
исходный контракт интерфейса. Полноценный браузерный и визуальный аудит на
контрольных ширинах остаётся отдельной внешней проверкой.
