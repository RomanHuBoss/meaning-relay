# Итерация 44 — визуальная система и VPS-контур

## Визуальная часть

- приглушены фоновые свечения и звёздный слой;
- унифицированы радиусы, границы, поверхности и тени карточек;
- выровнены hero-блок, публичные страницы, карта и административная панель;
- уточнены отступы и композиция первого экрана на мобильных ширинах;
- добавлены семантические CSS-токены для последующей синхронизации с Figma;
- верхняя навигация получила компактную стеклянную поверхность и фиксированную
  позицию при прокрутке;
- функциональные сценарии и API-контракты не менялись.

## VPS

- Next.js собирается в standalone-режиме;
- добавлен многослойный `Dockerfile` на Node.js 22;
- добавлен `docker-compose.vps.yml` с PostgreSQL 16, приложением и отдельным
  maintenance-контейнером;
- миграция и идемпотентный seed запускаются перед стартом приложения;
- добавлены healthcheck базы и приложения;
- `.env.example` и README описывают переменную пароля PostgreSQL и запуск на
  VPS.
