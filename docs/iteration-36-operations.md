# Итерация 36 — эксплуатационная защита журналов

Добавлен `tests/unit/operational-secret-scan.test.ts`.

Локальная проверка теперь просматривает исходники приложения, библиотеки,
общих пакетов и служебных сценариев и запрещает:

- прямую запись объекта ошибки или его стека в журнал;
- сериализацию объекта ошибки через `JSON.stringify`;
- вывод значений секретов из переменных окружения;
- изменение безопасного формата `event` и `error_name` у серверного и
  командного журналирования.

Проверка не утверждает, что внешняя система сбора журналов настроена, а также
не заменяет настоящий backup/restore, production HTTPS или доставку уведомлений.
Она фиксирует только свойство исходного кода, которое можно воспроизводимо
проверить локально.
