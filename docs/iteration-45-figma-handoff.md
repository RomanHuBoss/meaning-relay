# Итерация 45 — Figma handoff первого экрана

## Файл

- [Meaning Relay — Visual Direction 01](https://www.figma.com/design/1cYVHQEnFT9CmBAUU3TYFh)

Файл создан в команде Roman Rabinovich. Он предназначен для первого экрана
Meaning Relay и последующей синхронизации с Next.js-интерфейсом.

## Экран `Landing / Desktop`

- размер фрейма — 1440 × 1024;
- фон — `--color-bg-canvas`, глубокий сине-зелёный;
- верхняя навигация — стеклянная панель с логотипом, ссылками и действием
  `Вступить`;
- hero-блок разделён на текстовую колонку и орбитальную иллюстрацию;
- заголовок — `Передай мысль дальше.`;
- описание — `Один человек начинает фразу. Каждый следующий пересказывает её
  своими словами. В конце мы увидим, что пережило смысл.`;
- основное действие — `Вступить в цепочку ↗`;
- вторичное действие — `Посмотреть правила`;
- три карточки статистики — активные цепочки, завершённые цепочки,
  сохранённые ходы;
- нижняя секция — три шага `Прочитай`, `Перескажи`, `Передай`.

## Состояние синхронизации

Файл создан, библиотеки Material 3 Design Kit и Simple Design System найдены.
Экран собран в Figma как редактируемая структура на странице `Page 1`.
Основной фрейм имеет ID `8:2`, размер 1440 × 1024. Внутри находятся отдельные
текстовые слои, кнопки, карточки статистики, орбитальные кольца и три шага.
После визуальной проверки прозрачность контейнеров статистики и шагов исправлена,
а нижняя секция уменьшена так, чтобы полностью помещаться в экран.

Кодовая реализация синхронизирована с теми же пропорциями в
[components/relay-app.tsx](C:\AIGames\meaning-relay\components\relay-app.tsx:305)
и [app/globals.css](C:\AIGames\meaning-relay\app\globals.css:408).
