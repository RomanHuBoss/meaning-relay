# Итерация 29 — локальный UX и accessibility-контракт

## Сделано

- Добавлен единый `:focus-visible` контур для ссылок, кнопок и полей. Контур
  использует цвет акцента и остаётся видимым при клавиатурной навигации.
- Сохранён и проверен режим `prefers-reduced-motion: reduce`: анимации и
  переходы сводятся к минимальной длительности.
- Экран поиска свободного хода теперь объявляет состояние через `role=status`
  и `aria-live="polite"`.
- Обратный отсчёт хода объявляется через `aria-live` и `aria-atomic`, поэтому
  изменение секунд не теряется для скринридера.
- Экран ошибки получил связку `aria-labelledby` и стабильный `id`; действие
  возврата остаётся доступным с клавиатуры.
- Добавлены узкие правила для viewport до 360px: уменьшены внутренние поля,
  поля карточек и размер крупных заголовков; выбор страны переводится на всю
  ширину; горизонтальный overflow скрыт на уровне документа.
- Добавлен source-level тест `tests/unit/a11y-source.test.ts`. Он фиксирует
  проверяемые локально признаки доступности, не выдавая их за полноценный
  browser/axe audit.

## Проверки

Выполнить:

```bash
npm test -- tests/unit/a11y-source.test.ts
npm run typecheck
npm run lint
git diff --check
```

Полный keyboard traversal, контраст WCAG 2.2 AA, 320px screenshot и axe-прогон
по-прежнему требуют браузерной среды и отмечены в `docs/acceptance-ledger.md`
как внешние проверки.
