# Итерация 30 — матрица валидации текста

## Цель

Закрыть локально проверяемые границы длины и полный набор правил валидации
пересказа, не подменяя этим ручную проверку пользовательского UX.

## Что добавлено

- Параметризованные проверки границ в 20 и 500 Unicode code points, включая
  корректный подсчёт astral symbols через `Array.from`.
- Проверка граничных значений 19 и 501 code points.
- Проверка лимита в 60 слов и отказа на 61-м слове.
- Матрица отказов для control characters, backslash, HTML, URL, email,
  телефонного номера, платёжной карты и текста без слов.
- Проверка, что ровно 20 и 500 букв проходят длину без преждевременного
  отказа.

## Проверки

- `tests/unit/text.test.ts` — boundary/rule matrix passed;
- полный `npm test`, typecheck, lint и build выполняются корневой итерацией.

## Остаточный gate

Browser/axe, визуальная проверка счётчика и production PostgreSQL остаются
внешними проверками и не выдаются за локальное evidence.
