# Итерация 50. Арт-директорский слой и языковой контур

## Визуальное направление

- Создан персональный навык арт-директора для «Смыслового телефона» с правилами визуальной иерархии, русской терминологии, доступности и мобильной адаптации.
- В интерфейс добавлен единый космический слой для главной страницы, выбора языка, хода, результата, галереи, карты и панели администратора.
- Усилены стеклянные панели, холодные бирюзовые и фиолетовые свечения, лаймовый цвет действия, янтарный цвет истекающего времени и орбитальная карта ходов.
- Декоративные эффекты подчинены сценарию. Главный акцент остаётся на выборе языка, текущем ходе и передаче текста.

## Языки

- Поддержаны `ru`, `en`, `zh`, `fr`, `hi` и `es`.
- В RU-интерфейсе названия языков отображаются как «Русский», «Английский», «Китайский», «Французский», «Хинди» и «Испанский».
- API старта, галерея, админ-фильтры, приглашения и PostgreSQL enum принимают новые коды.
- Для новых языков пока используется английский исходный текст темы до появления отдельных переводов.
