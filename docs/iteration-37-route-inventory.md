# Итерация 37 — покрытие служебных HTTP-маршрутов

Добавлен `tests/unit/route-inventory.test.ts`.

Локально проверены маршруты, которые раньше имели только косвенное или
интеграционное покрытие:

- корневой health-маршрут и health-маршрут версии API без базы;
- административная панель: отказ гостю, сериализация статистики и безопасная
  ошибка при сбое хранилища;
- административный выход: успешная очистка cookie, очистка cookie при ошибке
  хранилища и отказ при неправильном CSRF;
- получение административной цепочки по публичному коду.

Проверка относится только к HTTP-контрактам и локальным заменам хранилища.
Реальная административная панель в браузере, HTTPS и PostgreSQL остаются
внешними этапами.
