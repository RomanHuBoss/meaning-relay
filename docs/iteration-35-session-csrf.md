# Итерация 35 — контракты сессии и CSRF

Добавлен `tests/unit/session-csrf-contracts.test.ts`.

Проверено локально:

- выдача нового CSRF-токена, атрибуты `SameSite`, `Max-Age` и отсутствие `HttpOnly`;
- сохранение корректного токена и замена короткого или некорректного значения;
- отказ создания сессии при отсутствии или несовпадении CSRF-заголовка;
- создание новой анонимной сессии с `HttpOnly` cookie, `SameSite=Lax` и тридцатидневным сроком;
- запись в PostgreSQL только производного 64-символьного идентификатора, без сырого значения cookie.

Комментарии в тесте фиксируют важное правило приватности: сырой идентификатор сессии
не должен попадать в запрос к базе данных.

Тесты не заменяют реальное HTTPS-поведение, чистую PostgreSQL и проверку cookie в браузере.
