# Итерация 36 — локальная модель конкурентных заявок

Добавлен `tests/unit/concurrency-inmemory.test.ts`.

Проверено в локальном синхронном адаптере:

- двадцать повторных стартов с одним ключом создают одну заявку: один исходный
  результат и девятнадцать повторов;
- двадцать повторных отправок с одним ключом создают одно сообщение и один
  переход цепочки;
- двадцать разных ключей после первой принятой отправки не создают второе
  сообщение и получают `IDEMPOTENCY_KEY_REUSED`;
- состояние цепочки и число сообщений остаются согласованными после всех
  попыток.

Тесты используют микрозадачи, чтобы воспроизвести наложение HTTP-вызовов вокруг
синхронного in-memory адаптера. Это доказывает локальную идемпотентность и защиту
перехода состояния, но не заменяет PostgreSQL race test с двадцатью реальными
транзакциями, уникальными индексами и блокировками.
