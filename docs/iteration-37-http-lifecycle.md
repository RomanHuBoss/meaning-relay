# Итерация 37 — матрица HTTP-жизненного цикла

Добавлен `tests/unit/http-lifecycle-matrix.test.ts`.

Проверены локально:

- приоритет CSRF перед доменным вызовом для start, submit и cancel;
- приоритет `SESSION_REQUIRED` перед CSRF для recover;
- сохранение анонимной cookie при ограничении start/report;
- остановка submit до обращения к relay при исчерпанном лимите;
- отображение ошибок start, submit, recover и report в безопасные HTTP-статусы;
- отсутствие внутренних деталей claim-токена в публичном сообщении ошибки.

Тесты не подменяют конкурентные PostgreSQL-транзакции, production HTTPS или
браузерный сценарий панели и пользовательского интерфейса.
