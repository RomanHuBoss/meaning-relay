# Итерация 11 — PostgreSQL seed для чистой базы

Добавлен `scripts/seed.mjs` и команда `npm run seed`. Скрипт работает в одной
транзакции, использует только параметризованные запросы и идемпотентен:

- создаёт или актуализирует пять активных тем;
- для каждого языка (`ru`, `en`) поддерживает по четыре активные chain на тему;
- получает 20 активных chains на язык на чистой базе;
- использует immutable title/seed snapshots при создании chain;
- не изменяет существующие chains, messages или terminal states.

Перед запуском нужна применённая `migrations/001_initial.sql` и
`DATABASE_URL`. Скрипт проверяет общий cap 50 active chains на язык и делает
полный rollback при ошибке.
