# Итерация 38 — публичная сериализация и XSS

Добавлен `tests/unit/public-xss-contracts.test.ts`.

Проверено локально:

- в исходниках приложения, компонентов, библиотек и служебных сценариев нет
  `dangerouslySetInnerHTML`, присваивания `innerHTML`, `document.write`, `eval`
  и динамического конструктора функций;
- разрешённый пользовательский текст передаётся в JSON как данные, а скрытый
  модератором текст заменяется безопасной заглушкой;
- административный сериализатор перечисляет поля сообщений вручную и не
  копирует внутренние хеши, адреса или другие служебные свойства через spread.

Проверка не подменяет браузерный axe/XSS-аудит и не утверждает безопасность
внешнего прокси или системы доставки журналов. Она фиксирует только свойства
исходного кода и локальных HTTP-сериализаторов.
