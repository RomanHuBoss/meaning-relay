# Итерация 38 — детерминированная длительная проверка обслуживания

Добавлен `tests/unit/maintenance-soak.test.ts`.

Локально проверено:

- обслуживание двадцати старых цепочек за один запуск;
- отмена двадцати действующих заявок при архивировании;
- повторный запуск без повторного подсчёта уже закрытых переходов;
- сохранение завершённой цепочки на двенадцати сообщениях;
- удаление только состарившихся служебных записей при очистке;
- неизменность публичной истории после повторного обслуживания.

Тест использует управляемые часы и синхронный in-memory-адаптер. Это
детерминированная проверка инвариантов и ограниченной очистки, но не измерение
боевой производительности, не проверка PostgreSQL и не подтверждение работы
внешнего планировщика.
