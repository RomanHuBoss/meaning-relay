# Итерация 39 — матрица JSON-тел HTTP-маршрутов

## Цель

Закрепить локально проверяемое поведение границ запросов для start, submit,
recover и report. Некорректное JSON-тело должно отклоняться до ограничения
частоты, создания сессии в рабочем контуре и вызова доменной модели.

## Что добавлено

`tests/unit/http-body-matrix.test.ts` проверяет 26 вариантов:

- `null`, массив и отсутствующие поля для start, submit и recover;
- неизвестные поля и значения неправильного типа;
- недопустимый язык и public code;
- неправильные типы claim token, country code и recovery key;
- повреждённый JSON;
- неизвестную причину жалобы;
- пустые, слишком длинные и имеющие неправильный тип подробности жалобы;
- отсутствие сессионной cookie для recover;
- отсутствие вызова rate limiter и relay для всех отклонённых тел.

Проверка не меняет формат ошибок и не подменяет реальные транзакции. Она
фиксирует порядок: синтаксис и структура тела проверяются до доменной операции.
PostgreSQL-конкурентность, HTTPS и браузерный прогон остаются внешними воротами.

## Проверка

Целевой набор: **26 тестов пройдено**.
