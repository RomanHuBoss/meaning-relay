# Итерация 40 — эксплуатационные контракты

## Что проверено

- маршрут обслуживания отклоняет отсутствующие, пустые, короткие, неверно
  оформленные и неверно написанные заголовки `Authorization`;
- ошибка обслуживания не раскрывает внутренний текст исключения и возвращает
  безопасный `503` с `request_id`;
- все методы, кроме `POST`, для служебного маршрута возвращают `405`;
- предварительная проверка конфигурации отклоняет нулевой, слишком короткий,
  дробный и нечисловой тайм-аут обслуживания;
- production-предварительная проверка запрещает локальный `PUBLIC_BASE_URL` и
  обычный HTTP вместо HTTPS.

## Ограничения

Проверки выполняются локально на заглушках и исходном коде. Они не подтверждают
работу настоящего PostgreSQL, HTTPS-прокси, Vercel Cron, резервного копирования,
доставки оповещений или внешнего хранилища журналов.
