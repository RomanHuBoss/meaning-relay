# Итерация 21 — безопасные CLI error logs

Миграция и seed больше не сериализуют произвольные ошибки в stderr: вместо
текста исключения выводятся только стабильное событие и имя класса ошибки.
Maintenance CLI также выводит только имя ошибки после сетевого сбоя или
таймаута. Это сохраняет диагностический сигнал и исключает попадание SQL,
endpoint-данных, пользовательских текстов и секретов в операционные логи.
