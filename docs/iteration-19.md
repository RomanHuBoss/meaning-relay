# Итерация 19 — race/idempotency smoke

Добавлен локальный race-style smoke для повторных `submit`-вызовов с одним
claim и одним `idempotency_key`. Два overlapping вызова должны завершиться
успешно: один создаёт сообщение, второй получает replay того же результата.

Проверяется инвариант цепочки: после повторной отправки остаётся ровно одно
сообщение, `currentHop` увеличивается только на один, а оба ответа содержат
один и тот же `message.id`. Настоящая PostgreSQL race/integration проверка
остаётся отдельным внешним gate и требует доступной базы.
