# Итерация 52. Объединение синего каркаса и экранных состояний

Визуальная система приведена к единому направлению по всем референсам.

- Синий космический каркас отвечает за сетку, статусные полосы, навигацию, тонкие технические линии и глубину сцены.
- Лаймовый сигнал используется для активного узла, выбранного языка и основного действия.
- Янтарный цвет используется для таймера и истекающего хода.
- Главная получила крупную дисплейную типографику с контурными строками.
- Экран выбора языка получил этап, широкие карточки языков и сильное выбранное состояние.
- Экран хода получил горизонтальную ленту из двенадцати узлов, крупный заголовок, цитату, таймер и памятку.
- Скругления уменьшены, а карточки переведены в более техническую форму с тонкими границами.

Проверены `typecheck`, `lint` и полный набор из 308 тестов.
