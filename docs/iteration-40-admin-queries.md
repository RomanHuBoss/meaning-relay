# Итерация 40 — административные списки и пагинация

Добавлен `tests/unit/admin-query-matrix.test.ts`. Он проверяет локально:

- фильтры темы, языка и состояния цепочки;
- фильтр состояния жалобы;
- размеры страницы `1` и `50`;
- отказ значений `0`, `51`, отрицательных и нечисловых значений;
- переход на вторую страницу по подписанному курсору;
- отказ повреждённого курсора до обращения к хранилищу;
- отсутствие служебных хешей в сериализованных темах, цепочках и жалобах;
- безопасный ответ `503` при недоступном административном методе.

Проверка остаётся локальным контрактом маршрутов и сериализаторов. Она не
подменяет настоящую PostgreSQL-пагинацию, конкурентный доступ и браузерную
проверку административного интерфейса.
