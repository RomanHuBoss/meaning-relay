# Итерация 5 — карта и галерея

В этой итерации публичный relay получил два read-only слоя поверх завершённых
данных эксперимента.

## Публичная галерея

Добавлен `GET /api/v1/chains` с фильтрами:

- `language=ru|en|all`;
- `theme=all|lower-case-slug`;
- `period=30d|365d|all`;
- `limit=1..12`;
- подписанный HMAC cursor по паре `completed_at + public_code`.

В галерею попадают только завершённые неархивированные chains. Ответ содержит
только публичный код, язык, snapshot темы, дату завершения и `target_hops`.
Seed и тексты сообщений остаются в отдельном публичном состоянии завершённой
цепочки.

## Карта активности

Добавлен `GET /api/v1/map?period=24h|all`.

Сервер возвращает только агрегаты `country_code + count`. Отдельная страна
показывается при пяти и более событиях; меньшие известные страны объединяются
в `OTHER`, отправки без выбранной страны — в `UNKNOWN`. В ответ не попадают
координаты, IP, session hash или message id.

Оба слоя реализованы для in-memory и PostgreSQL runtime. Для PostgreSQL
галерея использует фиксированную сортировку и tuple-cursor, а карта читает
только агрегированную таблицу `country_events` в заданном окне хранения.

## Публичные страницы

Добавлены страницы `/chains`, `/chains/{public_code}`, `/map` и `/about`.
Галерея поддерживает фильтры и дозагрузку следующей страницы, карта показывает
периодические агрегаты, локальную SVG-карту и доступную текстовую таблицу, а
страница правил объясняет механику эксперимента и приватность.
При `MAP_ENABLED=false` API и страница переходят в явный fallback с текстом о
временной недоступности карты и сохраняют публичные relay-счётчики.

Добавлена закрытая `/admin`-страница: ключ вводится только в память формы,
после входа доступны dashboard, списки тем/цепочек/жалоб и безопасные кнопки
pause/resume/archive и moderation actions. Секрет в `localStorage`,
`sessionStorage` или URL не сохраняется.
