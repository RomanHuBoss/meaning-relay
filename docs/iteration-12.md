# Итерация 12 — воспроизводимое применение миграций

Добавлены `scripts/migrate.mjs` и команда `npm run migrate`. Скрипт читает
версионированный `migrations/001_initial.sql`, выполняет его через PostgreSQL
client с тем же SSL-профилем, что и runtime, и закрывает соединение в любом
исходе.

При отсутствии `DATABASE_URL` команда завершается до открытия соединения;
ошибка SQL получает ненулевой exit code. Повторный запуск безопасен, поскольку
сама миграция использует `IF NOT EXISTS` и защитные enum blocks.
