# Итерация 35 — эксплуатационная документация

## Что добавлено

Добавлена команда `npm run verify:documentation`, которая проверяет согласованность
трёх источников эксплуатационной информации:

- `package.json` — команды, доступные оператору;
- `README.md` — порядок запуска, служебные endpoint’ы и production-предупреждения;
- `.env.example` — полный перечень переменных окружения.

Проверка также запрещает оставлять в README маркеры `TODO`, `TBD` и `FIXME`.
Это локальный контракт документации: он не утверждает, что PostgreSQL, HTTPS,
Vercel Cron или резервное копирование реально доступны в текущем окружении.

## Порядок запуска gate-проверок

Для локальной разработки достаточно выполнить:

```text
npm run typecheck
npm run lint
npm test
npm run verify:documentation
npm run verify:readiness
npm run verify:production
```

Для PostgreSQL-среза добавляется `npm run test:postgres`, а перед публикацией
необходимо отдельно пройти production HTTPS, миграцию на чистой базе, seed,
резервное копирование и ручной браузерный прогон. Эти проверки намеренно не
подменяются статическим контрактом документации.
