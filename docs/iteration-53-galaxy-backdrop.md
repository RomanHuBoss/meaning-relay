# Итерация 53. Галактический фон по синим референсам

Добавлен отдельный растровый фон `public/galaxy-nebula.png`.

Он используется как общая сцена для главной страницы, выбора языка, экрана хода и результата. В композиции сохранены тёмные зоны для текста, яркие бирюзовые туманности, фиолетовые глубины, звёздное поле, тонкие орбитальные дуги и тёплые янтарные акценты.

Поверх фона работают техническая статусная полоса, крупная дисплейная типографика, узловая лента эстафеты, glass-панели, таймер и памятка хода.
