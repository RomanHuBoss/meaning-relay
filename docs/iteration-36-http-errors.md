# Итерация 36 — матрица HTTP-ошибок

Добавлен `tests/unit/admin-login-error-matrix.test.ts`.

Локально проверены границы административного входа:

- неверный CSRF до ограничения частоты запросов;
- повреждённый JSON и тело-массив;
- отсутствующее и лишнее поле `admin_key`;
- неверный административный ключ без создания сессии;
- исчерпанное ограничение с ответом `429` и `Retry-After`;
- успешное создание административной сессии и её cookie.

Проверка работает на уровне HTTP-обработчика и изолированного хранилища. Она не
заменяет вход через боевой HTTPS, реальную базу данных и ручной браузерный
сценарий панели администратора.
