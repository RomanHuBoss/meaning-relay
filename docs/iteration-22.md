# Итерация 22 — нормализация operational log markers

`logSafeError` теперь принимает только безопасный набор символов в
`event`-метке и заменяет неподходящую метку на `unknown`. Имя ошибки больше не
берётся из `error.name`: даже вручную изменённое имя всегда нормализуется к
`Error` или `UnknownError`. Это исключает утечку секрета через нестандартный
объект ошибки или динамическое имя события.
